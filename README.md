Project title: Supervised and unsupervised machine learning



1. What is supervised learning?

Supervised learning is a type of machine learning in which a model is trained using labelled data to predict outcomes for new observations.

2. What is unsupervised learning?

Unsupervised learning is a type of machine learning in which a model is trained using unlabelled data to identify patterns, relationships, or groups.

3. What is the difference between supervised and unsupervised learning?

Supervised learning uses labelled data to predict outcomes, whereas unsupervised learning uses unlabelled data to discover patterns and groups within the data.

4. Why is Linear Regression considered supervised learning?

Linear Regression is considered supervised learning because it learns the relationship between input data, such as study hours, and known output values, such as examination scores, to make predictions.

5. Why is K-Means considered unsupervised learning?

K-Means is considered unsupervised learning because it groups data based on similarities without using predefined labels.

6. What is the purpose of fit() and predict()?

The fit() method trains the Linear Regression model using the available data, while predict() uses the trained model to estimate outcomes for new observations.

7. Give two applications each of supervised and unsupervised learning.

Supervised learning is applied in Email Spam Detection to classify emails as spam and filter unwanted messages from your inbox, and in Medical Diagnosis to analyse labelled medical images, such as X-rays, to help identify and classify medical conditions.

Unsupervised learning is applied in Customer Market Segmentation to group customers based on purchasing patterns and spending habits for targeted marketing, and in Anomaly Detection to identify unusual credit card transactions that may indicate fraudulent activity.
